Run two machine cycles

Name

Your job: follow two plain-English instructions. Every instruction goes through FETCH → DECODE → EXECUTE → WRITE.

MEMORY — instructions waiting to run
address 0: WRITE 5 TO REGISTER A
address 1: ADD 1 TO THE VALUE IN REGISTER A
STARTING STATE
PC = 0
IR = empty
Register A = unset

Cycle 1 — the PC points to address 0

1. FETCH

Copy the instruction at the PC into the IR. Then move the PC to the next address.

2. DECODE

In your own words, what is the instruction asking the machine to do?

3. EXECUTE

Determine the result the instruction will produce.

Do not update A until the write stage.

4. WRITE

Put the result into the decoded destination.

Checkpoint: PC =   Register A =

Cycle 2 — run the next instruction

1. FETCH

Use the current PC. Copy that instruction into the IR, then advance the PC.

2. DECODE

What operation, input, and destination does this instruction name?

3. EXECUTE

Use the current value in A and show the calculation.

4. WRITE

Put the result into the decoded destination.

Final check

PC =   Register A =

Model boundary: Real computers do not store English sentences as instructions. We are hiding how instructions are encoded so we can focus on the repeating machine cycle.
