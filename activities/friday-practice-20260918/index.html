Scenario 1 — Follow the payroll job
A payroll export begins as a stored file. The program loads records into RAM, the CPU processes them, the result remains in RAM, and the finished report is saved. Before one instruction runs: PC = 40, memory[40] = ADD 1 TO [201], and memory[201] = 7.
1. Which sequence best follows the job through the simplified machine?
A. Storage → CPU → output, skipping working memory.
B. RAM → storage → CPU, starting after the load.
C. Storage → RAM (load) → CPU/memory → storage/output (save).
D. Output → CPU/memory → storage, reversing the path.
E. Storage → output → RAM → CPU, bypassing the load.

D. IR contains ADD 1 TO [201], PC is 40, and memory[201] has become 8.
E. IR contains 7, PC is 201, and memory[40] has become 8.

D. The decode step changes address 201; the ALU reads the PC; write-back identifies ADD.
E. The decode step decodes ADD and [201]; the ALU makes 8; write-back stores 8.
