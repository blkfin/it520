Core D. Hex you have already seen

Every color on a web page can be written as a code like #FF0000. It is three bytes in hex: two characters for red, two for green, two for blue. Each byte says how much of that light to use, from 0 (none) to 255 (all of it).

  1. #FF0000: how much red, green, and blue is that, in decimal? What color is it? ______________________________
  2. Mystery color: #4EA1D6. Fill the table, then predict the color before you look it up.
