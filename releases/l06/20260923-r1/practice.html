Extension D. A new field for tote type

Another proposal on its own. The warehouse uses seven kinds of tote. The report should say which one kind the worker is filling.

  1. What is the smallest width that gives seven kinds seven different patterns? Show the comparison.
  2. How many patterns would be unassigned?
  3. A teammate says, “Seven kinds, so seven bits, one for each kind.” Under that scheme, how many bits are 1 at a time? Would seven bits work? Is it the smallest width?

Extension E. Field width, report size

The zone field designed in class is five bits wide. A teammate says, “So the report is five bits now.” In one or two sentences, say what the five bits are the width of, and why they do not tell you the size of the whole report.

Extension F. The scanner nobody updated

Before this year, scanners used an older layout: status in bits 7–6 with 00 Ready, 01 Busy, 10 Offline, 11 Fault; bits 5–4 spare; count in bits 3–0.

Scanner-03 was never updated. It sends 4D, which under the old layout means Busy with 13 items. The server reads every report with the current layout. What status and count does the server log? Why?
