Work with a partner. Use words and set notation; explain your choices. Complete the exit question yourself.

Our demo: each observation selects one label from S = {Sunny, Rain, Snow, Fog}. Rain and Snow indicate precipitation. Our fictional school starts On-time for Sunny/Rain and uses Delay for Snow/Fog.

Same predicates as the slides: P(x) = precipitation reported; Q(x) = school delayed.
NOT P(x) = no precipitation; NOT Q(x) = school on time.

Definitions: a set has distinct members; |A| counts them. N ∩ O means both; N ∪ O means either or both. A proposition is true or false; a predicate becomes a proposition when its inputs are supplied. AND requires both; OR includes both. A function assigns each input exactly one output. Domain = allowed inputs; codomain = declared output set; range = outputs attained over the whole domain.
