Hex digits: 0–9, then A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
Two hex digits: (left × 16) + right. One hex digit is 4 bits.
RLE format: each run is one record = 1 count byte + 1 symbol byte. Each letter of input is 1 byte.
Invariant: after each record, decoding the records so far gives exactly the input consumed so far.
Measure compression
ratio = compressed size ÷ original size (below 1: smaller; above 1: larger)
savings = (original − compressed) ÷ original
Time
send time (s) = size (MB) ÷ speed (MB/s)
compressed route = encode + send + decode
