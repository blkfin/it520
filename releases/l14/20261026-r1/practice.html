Byte order and caching: practice

Where do a number's bytes sit, and how fast are they read?

Part A. Byte order (about 8 minutes)

1. A debugger shows four bytes of memory, starting at address X:

AddressXX+1X+2X+3
Byte01000000

(a) Write the value these bytes hold, in hex, if the machine is little-endian. Then write it if the machine is big-endian.

(b) Can you tell from these four bytes alone which value the program stored? If not, what else would you need to know?

2. On another machine, a program stores the value 300, which is 0x0000012C. The debugger shows these bytes, starting at X:

AddressXX+1X+2X+3
Byte2C010000

Is this machine big-endian or little-endian? Name the byte that tells you. Why could you answer here but not in question 1?

3. A little-endian laptop sends the value 0x00C0FFEE to a server in a network message.

(a) Fill in the bytes, one per box.

Bytes, in order
Laptop memory, X to X+3
Network message, first byte sent to last

(b) The server is also little-endian. Does it need to convert the message? Suppose it skips converting: it puts the four message bytes, in the order they arrive, at X to X+3 and reads them with its own rule. What value does it get, in hex?

Part B. Caching (about 12 minutes)

Rules for every question in Part B

A miss copies the whole block into the cache. A full cache drops the copy used longest ago.

A hit takes 5 ns. A miss takes 100 ns. Each integer is 4 bytes.

4. Write temporal or spatial for each habit, and say in a few words what is used again or used next.

(a) A game reads the player's score every time it redraws the screen.

(b) A music player reads a song's sound samples one after another, in the order they are stored.

(c) A program compares every new temperature reading against the same highest-so-far value. Which habit does the highest-so-far value show?

5. A list of eight integers, items 0 to 7, sits side by side at bytes 0 to 31. Blocks are 16 bytes, so bytes 0 to 15 are one block and bytes 16 to 31 are another. The cache starts empty and has room for two blocks.

(a) The program reads items 0, 2, 4 and 6, in that order. Fill in the table.

(b) Next it reads items 1, 3, 5 and 7, which it has never read before. How many of these four reads miss? Is that temporal or spatial locality at work? Why?

A program adds up all 12 numbers. Row by row reads 1, 5, 9, then 2, 6, 10, and so on. Column by column reads 1, 2, 3, 4, then 5, 6, 7, 8, and so on. Start each order with an empty cache.

(a) For each order, count the misses and the hits, and give the total time.

(b) Which order is faster for this grid? Say why in one line.

7. Two programs each make 100 reads. Program P gets 98 hits and 2 misses. Program Q gets 90 hits and 10 misses.

(a) Give each program's total time.

(b) In program Q, which take more of the time: the 90 hits or the 10 misses?

(c) With no cache at all, every read goes to memory. How long would 100 reads take? What does that tell you about what the cache is for?
