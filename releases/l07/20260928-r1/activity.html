Read a thermostat controller's report

A small controller stores a four-bit temperature adjustment in degrees. It must represent warmer (+) and cooler (−) adjustments, so the controller writes the field in two's complement.

Reading shortcut for two's complement: if the first bit is 0, the value is the same as unsigned. If the first bit is 1, take the unsigned value and subtract 2width (16 for four bits, 256 for eight). Example: 1111 is 15 − 16 = −1.

Two diagnostic questions: (1) What is the field's width and reading rule? (2) Does the intended value or result fit that rule's range?
